# PromptPlayground

A simple app that compares how different system prompts affect AI responses.

## Features

- No prompt
- Assistant prompt
- Programmer prompt

## Setup

Install dependencies:

```bash
pip install -r requirements.txt
```

Create a .env file:

```env
OPENAI_API_KEY=your_api_key_here
```

Run:

```bash
streamlit run app.py
```

## Tech Stack

- Python
- Streamlit
- OpenAI API
